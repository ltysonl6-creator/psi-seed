# Ψ-SEED CACC v0.11 Verification Report

## Semantic Integrity Layer

v0.11 establishes a graph-level semantic integrity boundary on top of v0.10's
authoritative state projection and rollback semantics.

### Enforced creation-time rules

- SI-001: outcome causation chain must equal transition causation chain.
- SI-002: outcome timestamp may not precede transition timestamp.
- SI-003/SI-005: a rolled-back or invalidated transition cannot accept a new authoritative outcome.
- SI-004/SI-006: an outcome from a rolled-back transition cannot be promoted into developmental evidence.

### Audit-time rules

The semantic validator can inspect authoritative history directly, including data
created by lower-level import/legacy paths that bypass current service enforcement.
It reports contradictions without deleting or rewriting historical facts.

### Rollback semantics

A transition rollback now versions the transition lifecycle to `ROLLED_BACK`.
The original transition and all earlier outcomes remain in authoritative history.
The rollback is a new fact, not time travel.

## Tests

The v0.11 suite includes the prior v0.10 tests plus six semantic-integrity tests:

1. chain mismatch rejected
2. temporal inversion rejected
3. rollback lifecycle boundary enforced
4. rolled-back outcome rejected as developmental evidence
5. legacy semantic corruption detected by audit
6. valid history passes semantic audit

The suite should be run with:

```bash
pytest -q
```
